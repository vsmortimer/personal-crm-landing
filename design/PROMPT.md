Сверстай статичный лендинг «Личная CRM» на Astro + Tailwind CSS v4.

Материалы в этой папке:
- `HANDOFF.md` — спецификация: токены, типографика, раскладка каждого блока для мобильного и десктопа, состояния кнопки, доступность, SEO.
- `reference/mobile.html` и `reference/desktop.html` — эталонные макеты. Открой их в браузере и сверяйся; все размеры есть в инлайн-стилях. При расхождении со спекой прав референс.
- `src/styles/global.css` — токены в `@theme`, перенеси как есть.
- `src/content/landing.ts` — все тексты. Не переписывай и не сокращай копирайт; компоненты берут тексты только отсюда.

Требования:
1. Astro с `output: 'static'`, Tailwind 4 через `@tailwindcss/vite`, без `tailwind.config.js`. Ноль клиентского JS.
2. Шрифты — `@fontsource/cormorant-garamond` (500, 500-italic) и `@fontsource/manrope` (400, 500, 600), только подмножества cyrillic и latin.
3. Компоненты: `Layout.astro` (head, мета, шрифты), `AppButton.astro`, `ExampleCard.astro`, по компоненту на блок (`Hero`, `Familiar`, `HowItWorks`, `CardFields`, `Why`, `Final`, `Footer`), `pages/index.astro` собирает их.
4. Одна разметка на обе версии: мобильная — по умолчанию, десктопная — через `lg:` (≥ 1024 px). Планшет остаётся мобильной раскладкой в колонке 560 px.
5. Адрес кнопки — из `PUBLIC_APP_URL` (добавь `.env.example`).
6. Используй классы из токенов (`bg-paper`, `text-ink`, `font-display`…), а не произвольные hex-значения.

Готово, когда:
- `npm run build` проходит, в `dist/` один `index.html` без клиентских скриптов;
- страница визуально совпадает с референсами на 390 px и 1440 px, на 320 px нет горизонтального скролла;
- есть ровно две ссылки «Открыть приложение», обе на `PUBLIC_APP_URL`;
- пункты из раздела «Открытые вопросы» в HANDOFF.md оставлены как TODO в коде, а не заполнены выдуманными данными.
