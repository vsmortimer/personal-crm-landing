# Handoff: лендинг «Личная CRM» (стиль «Камень»)

## Обзор

Одностраничный статичный лендинг личной CRM. Единственное целевое действие — кнопка «Открыть приложение», ведёт на `PUBLIC_APP_URL` (`https://app.<домен>`). Кнопка повторяется дважды: на первом экране и в финальном блоке. Других ссылок, меню, форм и аналитики в макете нет.

**Стек:** Astro (output: `static`) + Tailwind CSS v4 (`@tailwindcss/vite`). JavaScript на клиенте не нужен — ноль `client:*` директив.

**Источники в пакете:**

| Файл | Что это |
|---|---|
| `reference/mobile.html` | Макет мобильной версии (ширина 390 px) — эталон для < 1024 px |
| `reference/desktop.html` | Макет десктопной версии (1440 px) — эталон для ≥ 1024 px |
| `src/styles/global.css` | Токены в `@theme` для Tailwind 4 — копировать как есть |
| `src/content/landing.ts` | Все тексты; компоненты берут копирайт только отсюда |
| `PROMPT.md` | Готовое задание для Claude Code |

Референсы — обычный HTML с инлайн-стилями: открываются в браузере, все размеры читаются из кода. При расхождении спеки и референса прав референс.

## Сетка и брейкпоинты

| Диапазон | Раскладка |
|---|---|
| < 1024 px | Мобильная: одна колонка, контейнер `max-w-[560px] mx-auto px-6`, вертикальные отступы блоков 64 px |
| ≥ 1024 px (`lg:`) | Десктопная: контейнер `max-w-[1280px] mx-auto px-16`, отступы блоков 112 px (финал 128 px) |

Планшет (768–1023) получает мобильную раскладку в колонке 560 px — это намеренно: текст не растягивается, а двухколоночные композиции на этой ширине тесные. Фоны блоков (sand, ink) идут на всю ширину окна, ограничен только контейнер внутри.

## Блоки

### Шапка (внутри hero)
Строка высотой 44 px (lg: 56), нижняя граница `line`. Слева логотип «Личная CRM», справа eyebrow «для своих». Не sticky, без навигации.

### Hero
- Мобильный: H1 (отступ сверху 48) → подзаголовок (24) → кнопка на всю ширину (32) → карточка-пример (40), нижний отступ блока 64.
- Десктоп: две колонки, `flex-wrap`, gap 64, выравнивание по центру. Левая (≈ 2/3): H1, подзаголовок `max-w-[520px]`, кнопка по ширине контента. Правая: карточка 340 px по центру колонки. Отступ от шапки 96.
- Слово «лично» — `<em>` курсивом в `accent`.
- **Карточка-пример:** прозрачный фон, рамка 1 px `line`, padding 20 (lg: 28), повёрнута `rotate(-2deg)` (lg: −3deg), max-width 280 на мобильном. Внутри: кружок 44 px (lg: 56) `line-soft` с инициалами (Cormorant 20/24) + имя (Manrope 600, 16/18) и «кто» (13/14, `ink-mute`); блок «Откуда знакомы» (метка + текст 13/14); блок с датой над линией `line-soft`. Это иллюстрация, не интерактив.

### 01 «Знакомо?»
Над блоком линия `line`. Eyebrow «01» → H2. Пункты — три абзаца Cormorant, каждый с верхней линией `line`, у последнего ещё и нижняя; padding 20/28 по вертикали. «Андрей ремонт» — курсив `accent`.
Десктоп: слева колонка заголовка (flex 1, min 280), справа пункты (flex 2, min 560), gap 64.

### 02 «Как это работает»
Фон `sand`. Нумерованный список `<ol>` (визуальные цифры — `aria-hidden`, порядок даёт сам `<ol>`).
- Мобильный: строка — цифра (ширина 28) + заголовок шага и текст, gap 20; между шагами 28.
- Десктоп: сетка `repeat(auto-fit, minmax(260px, 1fr))`, gap 48; у каждого шага верхняя линия `line-sand`, padding-top 24; цифра над заголовком.

### 03 «Что хранится в карточке»
Фон `ink`, текст `paper`, eyebrow и метки — `line-sand`.
- Мобильный: рамка `line-dark`, четыре строки с разделителями, padding 18×20; метка (uppercase 11) + описание 15. У «Телефон и почта» описания нет — только метка, строка от этого ниже, так и задумано.
- Десктоп: слева заголовок, справа сетка 2×2 в рамке `line-dark` с внутренними линиями, ячейки padding 32.

### 04 «Почему не просто контакты в телефоне»
Между «в» и «телефоне» неразрывный пробел. Три пункта: H3 курсивом в `accent` + текст `ink-soft`.
- Мобильный: стопка, gap 28.
- Десктоп: заголовок `max-w-[760px]`; пункты в сетке `repeat(auto-fit, minmax(260px, 1fr))`, gap 48, верхняя линия `line`, padding-top 24.

### Финал
Над блоком линия `line`. H2 «Начните с *одного* человека» → текст → кнопка на всю ширину.
Десктоп: `flex-wrap`, выравнивание по низу — H2 слева (flex 3, min 560), справа текст + кнопка на всю ширину правой колонки (flex 2, min 360).

### Подвал
Линия `line` сверху, padding 24 (lg: 32×64). Слева «Личная CRM» (Cormorant 18/22, `ink`), справа «2026» (13/14, `ink-mute`).

## Кнопка «Открыть приложение»

Один компонент `AppButton.astro`, используется дважды.

| Свойство | Мобильный | Десктоп |
|---|---|---|
| Элемент | `<a href={APP_URL}>` — это переход, не действие | |
| Размер | высота 56, ширина 100% | высота 60; в hero по контенту, в финале 100% колонки |
| Отступы | 0 24 | 0 28, gap 48 между текстом и стрелкой (hero) |
| Вид | фон `ink`, текст `paper`, radius 2, текст слева, стрелка справа | |
| Иконка | SVG-стрелка 20×20, stroke 1.6, `aria-hidden="true"` | |

| Состояние | Поведение |
|---|---|
| Hover | фон `ink-hover`, стрелка сдвигается вправо на 4 px; transition 150 ms ease-out |
| Focus-visible | outline 2 px `accent`, offset 3 px (глобально в `global.css`) |
| Active | фон `ink-hover`, без сдвига |

Ссылка открывается в той же вкладке, без `target="_blank"`. При `prefers-reduced-motion: reduce` сдвиг стрелки отключить.

## Доступность

- `<html lang="ru">`, один `<h1>`, далее `<h2>` у блоков и `<h3>` в блоке 04 — иерархия без пропусков.
- Структура: `<header>`, `<main>` с `<section aria-labelledby>` на каждый блок, `<footer>`.
- Номера «01–04» — декоративные, `aria-hidden="true"`.
- Карточка-пример в hero: `<figure aria-label="Пример карточки контакта">`; кружок с инициалами `aria-hidden`.
- Кнопки — настоящие `<a>`, зона нажатия ≥ 44 px (у нас 56/60).
- Фокус-порядок совпадает с порядком DOM: логотип не ссылка, значит первая точка фокуса — кнопка в hero, вторая — кнопка в финале.

## SEO и мета

- `<title>` и `<meta name="description">` — из `meta` в `landing.ts`.
- Те же значения в `og:title`, `og:description`, `og:type=website`, `og:locale=ru_RU`.
- `og:image` и фавикон в макете не заданы — **оставить TODO**, не придумывать.
- `<link rel="canonical">` — когда будет домен.

## Пограничные случаи

- **Длинные слова** в H1 на узких экранах (320 px): разрешить `hyphens: auto` для заголовков (lang=ru уже задан), проверить на 320 px, что ничего не вылезает за край.
- **Шрифты не загрузились:** fallback Times New Roman / system-ui; `font-display: swap` (по умолчанию у fontsource).
- **Повёрнутая карточка** не должна давать горизонтальный скролл — на мобильном обрезать `overflow-x: clip` на hero-секции.
- **Без JS** страница полностью работает — так и должно быть.
